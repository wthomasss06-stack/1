Site vitrine statique pour TechFlow Electronics, entreprise spécialisée dans les solutions électroniques en Côte d'Ivoire.

## 🌐 Démo en ligne

[Voir le site](https://votre-username.github.io/techflow-static)

## 🛠️ Technologies

- HTML5
- CSS3 (Tailwind CSS via CDN)
- JavaScript Vanilla
- Font Awesome Icons

## 🚀 Déploiement local
```bash
# Ouvrir directement index.html dans le navigateur
# OU utiliser un serveur local :
python -m http.server 8080
# Puis aller sur http://localhost:8080
```
